### 🚀 Featured Projects

#### 🏭 [Security & Badge Event Analysis](https://github.com/devpandey2010/SECURITY-AND-BADGE-EVENT-ANALYSIS)
Analyzed **88,728 badge-swipe events** at Tata Steel to quantify security and cost risk from access control patterns.
- Hypothesis testing to validate operational assumptions before drawing conclusions
- Power BI dashboards for security operations stakeholders
- Cost quantification tied to access-control inefficiencies
- Built with a strong self-correction trail — caught and fixed a wage assumption error, a unit conversion error, and a misclassification during analysis (documented in the repo)

#### 🦺 [RealWear Industrial Operations Analytics](https://github.com/devpandey2010/Realwear-Industrial-Analytics)
End-to-end analytics on **12,000 sessions across 5 plants** for RealWear Navigator 500 wearable-device usage in smart manufacturing.
- Statistical testing: **ANOVA, Welch's T-Tests, Chi-Square, Pearson correlation**
- Python EDA, SQL, and Power BI across the full pipeline
- Evaluated productivity, device health, communication efficiency, and operational KPIs

#### 🎣 [Phishing Classifier — End-to-End ML System](https://github.com/devpandey2010/FULL-STACK-MACHINE-LEARNING)
Full-stack ML project to detect phishing websites from URL, domain, and content-based features.
- Modular training/prediction pipeline (ingestion → validation → transformation → training → evaluation)
- **XGBoost, Logistic Regression, Naive Bayes** compared; up to **99% accuracy** with XGBoost
- Deployed via **Flask + Docker** on Render, with MongoDB Atlas and AWS S3 in the data/model flow

#### 🛒 [Olist SQL Business Analytics](https://github.com/devpandey2010/olist-sql-business-analytics)
**100 SQL business questions** on the Olist Brazilian e-commerce dataset, structured like real DA/BA/PA interview problems rather than syntax drills.
- Covers revenue, AOV, retention, cohorts, segmentation, and logistics SLA analysis
- Progressive difficulty: from basic reporting to executive-level strategic questions
- Joins, CTEs, window functions, and subqueries throughout
- Power BI folder for visualization layer
